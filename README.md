# mearhome.com

Jekyll sitesi; GitHub Pages yerleşik derleyicisiyle yayınlanır (Actions yok). İçerik yönetimi: Pages CMS (`.pages.yml`).

- Yerelde: `bundle install && bundle exec jekyll serve` → http://localhost:4000
- İçerik: `_posts/` (blog), `_urunler/` (ürün kartları), `setler/` (set sayfaları), `sayfalar/` (sabit sayfalar), `_data/` (ana sayfa metinleri, ayarlar, menü), `gorseller/` (medya)
- Şablon: `_layouts/`, `_includes/`, `assets/`
- Görsel hazırlama betikleri: `_arac/` (derlemeye girmez)
- Sahibi için: `Yonetim_Rehberi.md`, `DNS_Talimati.md`
